# SSB Poultry Website

## Project Overview
SSB Poultry is a poultry business website project created for the WEDE5020 Web Development portfolio.

The website is a mobile-first, five-page digital catalogue designed to showcase poultry products, prices, enquiries, contact details and store locations.

## Pages
- index.html — Home page
- about.html — About SSB Poultry
- products.html — Product catalogue and pricing
- enquiry.html — Product enquiry/order form
- contact.html — Contact details and branch locations

## Website Structure
The project uses semantic HTML5 elements and shared navigation across all five pages.

- css/style.css — Global stylesheet (reset, typography, header/nav, layout, cards, forms, footer, media queries)
